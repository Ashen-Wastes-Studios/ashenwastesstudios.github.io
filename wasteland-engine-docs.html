Overview

Wasteland Engine is a custom game engine built from scratch by Ashen Wasteland Studios. It supports 2D and 3D rendering with multiple graphics APIs and AI-powered path tracing through Nova Renderer.

Key Features

Multi-API Rendering

OpenGL, DirectX 11, DirectX 12, and Vulkan backends via NVRHI.

Nova Renderer

AI-powered ray tracing for denoising, upscaling, and intelligent sampling.

Volumetric Effects

Volumetric fog, raymarched clouds, and dynamic global illumination.

DemonCore Editor

Full editor with scene hierarchy, scripting, and AI chat panel.

Physics

Box2D for 2D, Box3D for 3D physics simulation.

Python Scripting

Full Python integration via pybind11 for game logic and tools.

Architecture

The engine is built with a layered architecture separating the core systems from the editor and tooling.

Project Structure

Wasteland/
├── Wasteland/                    # Main game engine library
│   └── vendor/                   # Third-party dependencies (GLFW, ImGui, NVRHI, etc.)
├── DemonCore-Editor/             # Editor application
│   └── src/Panels/               # Editor panels (AIChatPanel, SceneHierarchy, etc.)
├── Sandbox/                      # Test/sandbox application
├── docs/                         # Documentation (NVRHI setup guide, etc.)
├── scripts/                      # Build scripts (Win/Mac/Linux)
├── vendor/bin/premake/           # Premake build system
└── Wasteland.slnx                # Visual Studio solution

Clone the Repository

git clone https://github.com/Ashen-Wastes-Studios/Wasteland-Engine.git
cd Wasteland-Engine

Building

Step 1: Generate Project Files

PlatformCommand
Windows.\scripts\Win-GenProjects.bat
Linux./scripts/Linux-GenProjects.sh
macOS./scripts/Mac-GenProjects.sh

Step 2: Build NVRHI (Required for D3D11/D3D12/Vulkan)

cd Wasteland\vendor\nvrhi
mkdir build
cd build
cmake .. -G "Visual Studio 17 2022" -A x64
cmake --build . --config Release
cmake --build . --config Debug

Step 3: Build Wasteland Engine

# Windows (MSBuild)
msbuild Wasteland.slnx -property:Configuration=Release -property:Platform=x64

# Linux & macOS
make config=release_x64

Step 4: Run the Editor

# Windows
.\bin\Release-windows-x86_64\DemonCore-Editor\DemonCore-Editor.exe

# Linux
./bin/Release-linux-x86_64/DemonCore-Editor/DemonCore-Editor

# macOS
./bin/Release-macosx-x86_64/DemonCore-Editor/DemonCore-Editor

Nova Rendering Pipeline

Nova is the AI-powered rendering pipeline for 3D ray tracing:

  • Real-time path tracing with denoising
  • AI-powered upscaling (similar to DLSS)
  • Intelligent sample distribution
  • Volumetric fog and cloud raymarching
  • Dynamic global illumination
  • Render scale options: 0.5, 0.66, 0.8, 1.0

Scripting

Game logic can be written in Python using the pybind11 integration. The scripting engine is currently a work in progress and accepts contributions.

Tool Server

The ToolServer class provides AI agents with engine tools:

  • File operations (read, write, edit)
  • Memory management
  • Entity inspection
  • Scene manipulation

AI Tools

The engine includes a ToolServer that exposes engine functionality to AI agents. This enables autonomous AI-assisted development within the editor.

NVRHI Integration

NVRHI (NVIDIA Rendering Hardware Interface) provides DirectX 11, DirectX 12, and Vulkan backends. For detailed setup instructions, see docs/NVRHI_SETUP.md in the repository.

Key Points

  • Build NVRHI as a static library first
  • Both Debug and Release configs must be built
  • Vulkan SDK 1.3.296.0 is pinned
  • Supports runtime API switching
